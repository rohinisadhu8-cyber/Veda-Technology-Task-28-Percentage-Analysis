# Task 28 – Simple Percentage Analysis

## Project Overview
This project is part of the Veda Technology Internship (Task 28). The main objective is to calculate the percentage contribution of each product category using Microsoft Excel.

## Objectives
- Calculate total sales for each product category.
- Find the percentage contribution of each category.
- Create a percentage analysis table.
- Format percentages to two decimal places.
- Highlight the Grand Total.
- Create a pie chart for data visualization.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Pie Chart

## Methodology
1. Imported the Superstore dataset into Excel.
2. Created a Pivot Table.
3. Added Category to Rows and Sales to Values.
4. Calculated percentage contribution using Show Values As – % of Grand Total.
5. Formatted percentages to two decimal places.
6. Highlighted the Grand Total.
7. Created a pie chart to visualize category-wise sales contribution.

## Formula Used

Percentage Contribution = (Category Sales / Total Sales) × 100

## Key Learnings
- Understanding percentage analysis.
- Working with Pivot Tables.
- Calculating category-wise sales contribution.
- Formatting percentage values.
- Creating charts in Excel.

## Expected Outcome
A percentage analysis table showing each category's contribution to total sales, along with a pie chart for easy comparison.

## Conclusion
This task helped me understand how to perform simple percentage analysis in Microsoft Excel. It improved my skills in data summarization, percentage calculations, and data visualization.
